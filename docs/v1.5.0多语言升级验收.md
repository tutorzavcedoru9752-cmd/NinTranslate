# NinTranslate 1.5.0 多语言升级验收

## 新增能力

- 离线 OCR 支持：简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、俄语。
- 百度翻译使用 `from=auto`；Microsoft Translator 在自动识别时省略 `from`。
- 默认目标语言保存在设置中，旧设置自动补为简体中文。
- 结果页可临时切换目标语言，不重新截图、不重新 OCR，也不改变长期默认值。
- 连续切换目标语言时只接受最后一次请求的结果。
- 同一次截图重翻译会更新原历史记录，不产生重复记录。

## 隐私与体积

- 十个压缩 OCR 模型共 18,143,007 字节；原中英模型共 4,671,641 字节，净增加 13,471,366 字节。
- 截图只在内存中参与 OCR；历史仍只包含文字字段。
- 百度或微软只接收 OCR 文字、源语言和目标语言。

## 自动化验收命令

```powershell
npm.cmd run typecheck
npm.cmd test -- --run
npm.cmd run test:ocr
npm.cmd run build
npm.cmd run dist:win
```

## 手动验收步骤

1. 在设置页将默认目标语言改为日语并保存，重新打开设置确认仍为日语。
2. 分别截图英语、日语、俄语和繁体中文文字，确认能识别且显示检测到的源语言。
3. 在结果页把目标语言改为简体中文，确认不重新截图即可获得新译文。
4. 连续快速选择两个目标语言，确认最终译文对应最后一次选择。
5. 打开历史记录，确认同一截图只有一条最新记录。
6. 检查复制、固定、交换、调整大小、重试与清空历史功能。

## 实机状态

- Windows x64：本地安装版与便携版构建成功，包内十个 OCR 模型和新增 IPC 已核验；仍需在独立 Windows 10/11 电脑完成安装与交互验收。
- macOS arm64/x64：由 GitHub Actions 构建，仍需真实 Mac 完成截图与在线翻译验收。
