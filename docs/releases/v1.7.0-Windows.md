# NinTranslate 1.7.0 · 界面升级（Windows）

本版全面整理设置、翻译结果与历史界面，保留熟悉的蓝色品牌标识，并收入此前的 Windows 原生截图响应修复。

## 更新内容

- 统一 SVG 图标、系统字体层级、间距、圆角与深浅色语义配色。
- 设置页按用途分组；高级服务端点默认折叠，测试连接与保存状态分别反馈。
- 翻译结果清晰显示识别语言；优化编辑、交换、复制、固定及调整大小入口，小窗口仍能分别滚动查看原文和译文。
- 历史页优化搜索、复制、删除、确认清空与空状态。
- 补齐键盘焦点、禁用状态、高对比度与减少动态效果；不显示处理耗时。
- Windows 使用原生选区层，减少闲置后唤起隐藏浏览器和传输整屏画面的等待；异常退出后自动恢复。

## 下载与升级

- `NinTranslate-1.7.0-Setup-x64.exe`：Windows 10/11 64 位安装版。
- `NinTranslate-1.7.0-Portable-x64.exe`：Windows 64 位便携启动版。
- `NinTranslate-1.7.0-Source.zip`：包含模型与构建说明的源码包。
- `SHA256SUMS.txt`：以上三个文件的 SHA-256 校验值。
- `Guide-zh-CN.md` 与 `Acceptance-zh-CN.md`：中文操作说明、检查证据及限制。GitHub 附件使用英文文件名，内容仍为中文；本地交付目录保留中文文件名。

升级前请先从系统托盘完全退出旧版，再安装新版本；安装版通常沿用原有设置与凭据。不要向他人发送自己的应用数据目录或 API 密钥。

此版 Windows 文件未使用可信发行证书签名，可能出现 SmartScreen 提醒。请核对 SHA-256，仅在确认来源可信后运行。

## 验证与边界

类型检查、正式打包、70 项单元测试、59 项最终包 UI 检查、9 项最终包原生截图检查通过。UI 自动化使用合成数据及隔离的 IPC 后端，不等价于真实翻译账户测试；已在包内实际运行中英文、日语与俄语 OCR。

本次仅发布 Windows；未重新构建、签名或验收 macOS，也未在全新电脑上完成安装升级卸载测试。使用 `windows-v1.7.0` 标签区分此次 Windows 交付，避免触发已有的全平台自动构建。源码位于此发布标签对应提交；主分支的合并通过单独 PR 管理。
