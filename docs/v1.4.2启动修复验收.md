# NinTranslate 1.4.2 macOS 启动修复验收

## 用户可见问题

设置页点击“测试连接”后显示：

```text
Error invoking remote method 'settings:test':
Error: No handler registered for 'settings:test'
```

## 根本原因

macOS 启动流程在注册 IPC 之前设置 Dock 图标，但安装包的额外资源清单没有包含 `nintranslate-app-icon.png`。图标加载失败会中断启动初始化，设置窗口仍可能被 macOS 激活事件打开，但核心 IPC 服务没有注册。

## 修复

- 将 `nintranslate-app-icon.png` 加入安装包额外资源。
- 将全部 IPC 注册提前到可选 UI 初始化之前。
- Dock 图标和菜单栏图标初始化分别隔离异常。
- 即使图标资源异常，百度测试、设置、历史和截图 IPC 仍保持可用。
- macOS 构建任务检查安装包中真实存在 Dock 图标。
- macOS 构建任务检查编译后的主进程包含 `settings:test`。

## Mac 实机复测

1. 从菜单栏完全退出旧版 NinTranslate。
2. 安装并覆盖为 1.4.2。
3. 打开 Finder“应用程序”，确认简介中的版本为 1.4.2。
4. 填写百度 APP ID 和密钥。
5. 点击“测试连接”。
6. 不应再出现“No handler registered”。
7. 正确凭据应显示“连接成功：Hello → 你好”。
8. 失败或断网时应在 20 秒内显示明确错误并恢复按钮。
