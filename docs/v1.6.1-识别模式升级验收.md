# NinTranslate 1.6.1 识别模式升级验收

## 本次升级

- 设置页新增“中英快速（推荐）”和“多语言自动识别”两种文字识别模式。
- 中英快速模式只运行一次中英 PP-OCRv5 Mobile 模型，不加载其他语种识别器，也不自动调用 Server 高精度模型。
- 多语言模式保留原有十语种识别、候选结果比较和低置信度高精度回退。
- 两种模式都保留本地版面分析、智能分段、原文编辑和历史记录功能。
- 结果页“原文”标题明确显示翻译服务检测出的语言，底部显示本次使用的识别模式。
- 按照用户要求，界面不显示 OCR 或翻译耗时。

## 兼容与隐私

- 旧设置缺少识别模式时自动使用中英快速模式，不需要迁移密钥或历史。
- 非法或未知的识别模式会回退到中英快速模式。
- 模式只影响后续截图，不修改历史数据。
- 截图仍只在本机内存中处理，翻译服务仍只接收识别后的文字。

## 自动验收

- 类型检查与生产构建通过。
- 常规单元测试覆盖模式白名单、旧设置迁移和无效值回退。
- OCR 集成测试覆盖中英快速模式只选择 CJK Mobile、不会触发高精度模型，并继续覆盖多语言十语种与真实截图夹具。
- 设置页和结果页已在 820px 设置窗口、440px 标准结果窗及 360px 最小结果窗检查。
- 浅色和深色模式下，语言提示、模式下拉框、文字、边框和禁用状态均保持清晰。
