# NinTranslate 1.7.0 界面升级验收

交付日期：2026-10-16。平台：Windows x64，Electron + React。此次发布包含本地尚未上传的 1.6.2/1.6.3 截图响应修复；不构建或发布 macOS 安装包。

## 设计与实现

按 UI 设计系统与原生平台 Skill 执行：复用原有蓝色标识、React 技术栈与系统字体，不新增字体下载、组件库或运行依赖。

- 颜色通过语义 Token 管理：画布、表面、边框、正文、辅助文字、品牌、成功、危险、焦点等；浅色与深色分别定义，不依赖固定白色背景。
- 统一 20/24 像素描边 SVG 图标与 6/10/16 像素圆角；设置页标题、区块、正文与说明有明确层级。
- 设置页分组、折叠高级端点、未保存提示、独立的测试/保存反馈；底部保存区域参与布局，不遮挡滚动内容。
- 结果页保留识别语言、当前目标语言、原文编辑、交换、复制、固定、尺寸预设、重试。交换按钮置于正常布局，避免压住文本。
- 历史记录重排为清晰的原文/译文卡片，提供搜索、清空搜索、删除、清空确认和空状态。
- 小尺寸窗口使用自适应布局；结果窗最小 360×320 DIP 时两块文本都保留独立滚动区域。设置窗默认 960×760 DIP、最小 700×560 DIP。
- 补齐键盘焦点、按钮名称、选中/禁用状态、编辑器快捷键和输入法组合输入保护；支持减少动态效果与 Windows 强制颜色。
- 截图入口不增加动画或模糊效果；产品界面不展示识别/处理耗时。

## 未验证与注意事项

- 本次没有真实 Mac 验收、Mac 远程 CI、签名或公证；不将 Windows 检查结果泛化为 Mac 已通过。
- 尚未在另一台无开发环境电脑上验证此次安装/覆盖升级/卸载；本机验收基于正式包内程序，不等价于干净机器安装测试。
- 本次未重新跑完整十语种夹具套件；当前包实际复验了中英文、日语和俄语截图，不宣称任何图文都能无错识别。
- 未用真实账户重新测试百度/微软接口，网络、额度与凭据仍由用户环境决定。
- Windows 文件的 Authenticode 状态为 NotSigned，可能出现 SmartScreen 提醒。仅从可信发布页下载，并与 SHA-256 清单核对。
- 保留既有性能修复，但不同电脑负载会影响响应；不承诺与微信或 Snipaste 在所有设备上延迟完全一致。
