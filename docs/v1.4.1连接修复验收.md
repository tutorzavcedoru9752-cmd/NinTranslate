# NinTranslate 1.4.1 连接修复验收

## 修复目标

解决 macOS 设置页测试百度翻译连接时，界面可能长期停留在“处理中”的问题。

## 原因

底层翻译请求虽然已有超时，但设置页缺少完整的异常恢复和独立的 IPC 超时。如果主进程通信拒绝或没有返回，界面不会执行状态复位。

## 修复内容

- 百度翻译请求设置 12 秒截止时间。
- 主进程连接测试设置 16 秒独立截止时间。
- 设置页设置 20 秒最终截止时间。
- 设置页使用 `finally`，确保成功、失败、拒绝和超时都会恢复按钮。
- 用户已经输入完整的新凭据时，不再读取旧的系统钥匙串凭据。
- 钥匙串异常转换为可见错误，不再让 IPC 直接拒绝。

## Mac 实机复测

1. 安装 NinTranslate 1.4.1。
2. 填写百度 APP ID 与密钥。
3. 点击“测试连接”。
4. 正常网络和正确凭据应显示“连接成功”。
5. 错误凭据应显示具体错误。
6. 断网时最晚 20 秒内恢复按钮并显示超时或网络错误。
7. 不应再出现持续数分钟的“处理中”状态。
