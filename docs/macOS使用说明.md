# NinTranslate macOS 使用说明

## 选择正确的安装包

- Apple 芯片 Mac（M1、M2、M3、M4 等）：下载文件名含 `arm64` 的 `.dmg`
- Intel 芯片 Mac：下载文件名含 `x64` 的 `.dmg`

点击屏幕左上角的苹果菜单，选择“关于本机”，即可查看“芯片”或“处理器”类型。

## 安装

1. 双击下载的 `.dmg`。
2. 把 NinTranslate 拖入“应用程序”文件夹。
3. 从“应用程序”中打开 NinTranslate。

当前测试包没有使用 Apple Developer 证书签名。如果系统阻止打开：

1. 在 Finder 的“应用程序”中找到 NinTranslate。
2. 按住 Control 点击应用图标，选择“打开”。
3. 在弹窗中再次选择“打开”。

也可以前往“系统设置 → 隐私与安全性”，在安全提示附近点击“仍要打开”。

## 授予截图权限

第一次截图时，macOS 会要求“屏幕与系统音频录制”权限：

1. 打开“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”。
2. 打开 NinTranslate 右侧的开关。
3. 完全退出 NinTranslate，然后重新打开。

NinTranslate 只在内存中处理所选截图，不保存截图，也不会把截图发送给翻译服务。

## 开始截图翻译

- 默认快捷键：`Command + Shift + T`
- 也可以点击菜单栏中的 NinTranslate 图标，再选择“截图翻译”

拖动鼠标框选文字区域，松开后会执行本地 OCR，并显示翻译结果。

## 配置翻译服务

首次使用需要在设置页填写自己的百度翻译 APP ID 和密钥，或者选择 Microsoft Translator。

凭据会通过 macOS 系统安全存储加密，界面页面不能读取明文凭据。

## 常见问题

### 快捷键没有反应

该组合键可能被其他软件占用。打开 NinTranslate 设置页，换用其他 Electron 快捷键格式，例如 `CommandOrControl+Shift+Y`。

### 截图显示桌面背景或空白

确认已经授予屏幕录制权限，并在修改权限后完全退出、重新打开 NinTranslate。

### Apple 芯片提示应用不兼容

确认下载的是文件名含 `arm64` 的版本，不要下载 `x64` 版本。

### Intel Mac 无法启动

确认下载的是文件名含 `x64` 的版本。
