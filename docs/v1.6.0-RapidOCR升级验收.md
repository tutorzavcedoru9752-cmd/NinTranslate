# NinTranslate 1.6.0 RapidOCR 升级验收

## 本次升级

- 本地 OCR 从 Tesseract.js 更换为 RapidOCR 3.8.1、PaddleOCR PP-OCRv5 模型和 ONNX Runtime。
- 简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语和俄语继续离线识别。
- 每张截图会在四套识别字库中比较文字完整度、置信度和字符体系，选出最合理结果，降低错认成其他语言的概率。
- 新增 PP-OCRv5 Server 高精度识别模型作为智能回退：快速结果置信度不足时才惰性运行，并继续使用更适合 UI 整行文字的 Mobile 检测器。
- 集成 RapidLayout 1.2.1 和两套 Apache-2.0 的 PaddleOCR 版面模型，按主要文字体系选择模型；先重建同一基线文字框，再结合连续水平分隔线、稳健 XY-cut 多栏排序、标点和行距整理段落。
- 结果页显示、编辑、翻译和历史共用同一份规范化原文；用户可编辑错字或人工换段并重新翻译。
- 结果页增加“智能分段 / 保留视觉行 / 合并为一段”，切换时不重新截图或 OCR；人工编辑后自动重排被锁定。
- 深色背景会在内存中转换为灰度 OCR 输入，消除浏览器彩色子像素边缘造成的漏行；版面模型仍读取原始内存图像。
- 深色模式下的原生下拉框、选项列表和聚焦状态使用明确的深色底与浅色文字。

## 隐私与资源

- 截图以 Base64 数据通过本机进程管道送入 OCR，仅在内存中处理，不写入历史或临时图片文件。
- 翻译服务仍只接收整理后的文字、源语言和目标语言，不接收截图。
- 历史记录结构不变，只保存文字。
- 七个 PP-OCRv5 模型与两个版面模型合计 151,188,154 字节（144.18 MiB），构建时逐个校验 SHA-256；缺少或被修改时构建立即失败。
