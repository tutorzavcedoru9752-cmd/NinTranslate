# NinTranslate 1.6.0 RapidOCR 升级验收

## 本次升级

- 本地 OCR 从 Tesseract.js 更换为 RapidOCR 3.8.1、PaddleOCR PP-OCRv5 模型和 ONNX Runtime。
- 简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语和俄语继续离线识别。
- 每张截图会在四套识别字库中比较文字完整度、置信度和字符体系，选出最合理结果，降低错认成其他语言的概率。
- OCR 原文仍按截图布局显示；翻译前额外进行语义文本整理，使视觉换行不再轻易截断句意。
- 深色模式下的原生下拉框、选项列表和聚焦状态使用明确的深色底与浅色文字。

## 隐私与资源

- 截图以 Base64 数据通过本机进程管道送入 OCR，仅在内存中处理，不写入历史或临时图片文件。
- 翻译服务仍只接收整理后的文字、源语言和目标语言，不接收截图。
- 历史记录结构不变，只保存文字。
- 六个 PP-OCRv5 模型合计 51,774,453 字节，构建时逐个校验 SHA-256；缺少或被修改时构建立即失败。
